# LESSON_OUTLINE — Урок_23_Feature_Engineering_Теория

- **Теория / упражнения:** занятие 23
- **Практика:** занятие 24 (следующий урок)
- **Формула:** уроки идут по порядку с 21

## Сквозной пример

- **Задача:** предсказать **цену** квартиры по объявлению (регрессия).
- **Данные:** таблица объявлений `flats` (~15 строк): площадь, комнаты, район, дата объявления, балкон, состояние, просмотры за месяц, доход района (NaN).
- **Проверка идей:** `KNeighborsRegressor` + `StandardScaler`, split 70/30, `random_state=42`, метрика MAE.

## План теории (19 разделов)

0. Шапка: определение конструирования признаков, цели, сквозной датасет + code (загрузка `flats`, split)
1. Что делает признак хорошим (5 критериев, момент прогноза)
2. Отношения и разности (+ code: площадь_на_комнату)
3. Логарифмирование скошенных величин (+ code: log1p просмотров)
4. Интервалы и ограничение выбросов (+ code: pd.cut по площади)
5. Нелинейность и взаимодействия (+ code: площадь × балкон)
6. Как увидеть пользу взаимодействия (+ code: график наклонов)
7. Даты и цикличность * (+ code: месяц, sin/cos)
8. Время с события (+ code: дней с публикации)
9. `ColumnTransformer` для разных правил обработки колонок
10. Категориальные признаки и one-hot внутри `ColumnTransformer`
11. `Pipeline`: подготовка признаков и модель в одной цепочке
12. Порядковые категории (+ code: OrdinalEncoder по состоянию)
13. Редкие и неизвестные категории (+ code: handle_unknown)
14. Пропуски и индикатор (+ code: доход района, медиана train)
15. Почему пропуски появились
16. Агрегаты по прошлому и утечка; target encoding * — предупреждение
17. Масштабирование (+ code: StandardScaler fit на train)
18. Проверка признака на validation (+ code: kNN, MAE двух наборов)
19. Стоимость признака и чек-лист

## Практика (занятие 24, задания 0–9, ~90 мин)

Полный цикл на flats: постановка → split → базовые признаки → даты → категории → пропуски → масштаб → kNN сравнение наборов → итог.
