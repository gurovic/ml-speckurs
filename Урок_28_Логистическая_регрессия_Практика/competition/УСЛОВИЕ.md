# Дойдёт ли ученик до конца курса

Онлайн-курс хочет заранее понять, кто из учеников, скорее всего, дойдёт до конца. Если модель видит высокий риск бросить, куратор может мягко напомнить про задания, предложить помощь или пригласить на разбор.

Вам нужно построить модель, которая по данным об ученике в начале обучения предсказывает, завершит ли он курс.

## Что предсказать

Одна строка таблицы — один ученик на курсе.

Целевая переменная — `will_finish`: `1` — ученик завершил курс, `0` — не завершил. Этот столбец есть только в `train.csv`. Для учеников из `test.csv` ответ нужно предсказать.

Тип задачи — бинарная классификация. На этом занятии используйте логистическую регрессию (`LogisticRegression`).

Модель сначала выдаёт вероятность класса 1, затем вы сами выбираете порог и получаете итоговый класс 0 или 1.

## Метрика

**F1** по столбцу `will_finish`. Больше — лучше.

F1 учитывает сразу две вещи: скольких будущих выпускников модель нашла и скольких пометила зря. Если модель почти никого не отмечает или, наоборот, ставит «завершит» почти всем, F1 будет низким.

Порог 0.5 не обязан быть лучшим. Его стоит подобрать на validation.

Ответы для test скрыты. Качество на таблице лидеров считает тестирующая система по вашему файлу `submission.csv`. Главная метрика считается по столбцу `will_finish`.

## Файлы

| Файл | Что внутри |
|---|---|
| `train.csv` | 800 учеников с признаками и ответом `will_finish` |
| `test.csv` | 350 учеников только с признаками |
| `sample_submission.csv` | пример файла ответа: столбцы `id`, `probability`, `will_finish` |

Обучаться и сравнивать идеи можно только по `train.csv`. Файл `test.csv` нужен только для финального прогноза.

Перед обучением посмотрите долю класса 1, типы столбцов и пропуски. При разбиении train на train и validation сохраняйте долю классов (`stratify`).

## Признаки

| Столбец | Смысл |
|---|---|
| `id` | номер ученика; в модель не входит |
| `age` | возраст, лет |
| `practice_hours_week` | сколько часов в неделю ученик занимается |
| `homework_rate` | доля сданных домашних заданий, от 0 до 1 |
| `last_score` | балл за последнюю работу, от 0 до 100 |
| `missed_classes` | сколько занятий пропустил |
| `club_visits` | сколько раз приходил в учебный клуб |
| `distance_min` | время в пути до занятий, минуты |
| `internet_quality` | качество интернета: низкое, среднее, высокое |
| `parent_support` | как часто помогают дома: редко, иногда, часто |
| `course_level` | уровень курса: стартовый, средний, продвинутый |
| `favorite_subject` | любимый предмет |
| `has_friend_in_group` | есть ли друг в группе: 1 — да, 0 — нет |
| `joined_trial` | ходил ли на пробное занятие: 1 — да, 0 — нет |
| `messages_to_teacher` | сколько раз писал преподавателю |
| `will_finish` | завершил ли курс; только в `train.csv` |

## Что сдать

Файл `submission.csv` с тремя столбцами:

- `id` — те же номера, что в `test.csv`;
- `probability` — вероятность класса 1, число от 0 до 1;
- `will_finish` — итоговый прогноз, 0 или 1.

Число строк должно совпадать с `test.csv`. Порядок `id` лучше сохранить как в `test.csv`.
