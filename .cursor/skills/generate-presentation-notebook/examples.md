## 2. Блок «Что видно» после графика

**Методичка:**

> **Что видно.** При `k=1` train-accuracy = 1.0, validation падает. При большом `k` обе кривые сближаются, но качество на validation хуже оптимума. Оптимум здесь около `k=7`…

**Presentation:**

```markdown
**Обсудим:**

1. Почему train при `k=1` идеальный, а validation — нет?
2. По какой кривой выбираем `k` — train или validation?
```

*(ячейка с графиком — как в методичке)*

```markdown
> **Вывод.** `k` подбираем по **validation**. Слишком маленький `k` — переобучение, слишком большой — модель «слишком гладкая».
```

## 6. Чего не делать

| Плохо | Почему |
|-------|--------|
| Скопировать все абзацы методички и вставить «Обсудим» сверху | Это снова самоучитель |
| Вопрос и ответ в одной ячейке | Нет паузы для класса |
| Сначала все вопросы урока, потом вся демонстрация, потом все выводы | Не похоже на живой урок у доски |
| Новый пример/датасет «для красоты» | Расхождение с методичкой и практикой |
| Перенумеровать разделы | Ломаются ссылки п. N |
| Десять вопросов подряд без графика | Темп доски падает, диалог выдыхается |
