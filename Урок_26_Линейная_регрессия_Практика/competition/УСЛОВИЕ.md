# Цена квартиры по объявлению

Сервис объявлений хочет автоматически оценивать цену квартиры, когда пользователь публикует новое объявление. Если оценка сильно расходится с указанной ценой, модератор может проверить объявление вручную: слишком дешёвое часто оказывается ошибкой или подозрительным, слишком дорогое хуже продаётся.

Вам нужно построить модель, которая по полям объявления предсказывает цену.

## Что предсказать

Одна строка таблицы — одно объявление о квартире.

Целевая переменная — `price_mln`, цена в миллионах рублей. Этот столбец есть только в `train.csv`. Для объявлений из `test.csv` цену нужно предсказать.

Тип задачи — регрессия. На этом занятии используйте линейные модели: `LinearRegression`, `Ridge`, `Lasso` или `ElasticNet`.

## Метрика

**MAE** — средняя абсолютная ошибка в миллионах рублей. Меньше — лучше.

Если MAE равна 0.6, модель в среднем ошибается на 0.6 млн рублей.

Ответы для test скрыты. Качество на таблице лидеров считает тестирующая система по вашему файлу `submission.csv`.

## Файлы

| Файл | Что внутри |
|---|---|
| `train.csv` | 700 объявлений с признаками и ценой `price_mln` |
| `test.csv` | 300 объявлений только с признаками |
| `sample_submission.csv` | пример файла ответа: столбцы `id` и `price_mln` |

Обучаться и сравнивать идеи можно только по `train.csv`. Файл `test.csv` нужен только для финального прогноза.

В выгрузке объявлений встречаются пропуски, опечатки и странные значения. Перед обучением посмотрите типы столбцов, уникальные категории и подозрительные числа.

## Признаки

| Столбец | Смысл |
|---|---|
| `id` | номер объявления; в модель не входит |
| `area_m2` | площадь квартиры, м² |
| `rooms` | число комнат |
| `kitchen_m2` | площадь кухни, м² |
| `floor` | этаж квартиры |
| `floors_total` | сколько этажей в доме |
| `district` | район |
| `condition` | состояние отделки |
| `distance_to_center_km` | расстояние до центра, км |
| `metro_min` | время до метро, минуты |
| `metro_h` | время до метро, часы |
| `house_age` | возраст дома, лет |
| `has_balcony` | есть ли балкон: 1 — да, 0 — нет |
| `ceiling_height` | высота потолков, м |
| `views_30d` | сколько раз объявление открывали за 30 дней |
| `listing_month` | месяц, когда объявление опубликовали |
| `price_mln` | цена в млн рублей; только в `train.csv` |

У части объявлений `metro_min` и `metro_h` могут быть пустыми.

## Что сдать

Файл `submission.csv` с ровно двумя столбцами:

- `id` — те же номера, что в `test.csv`;
- `price_mln` — ваш прогноз цены.

Число строк должно совпадать с `test.csv`. Порядок `id` лучше сохранить как в `test.csv`. Цена не может быть отрицательной.
